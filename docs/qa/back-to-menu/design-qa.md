# Relic hunt: a way back to the main menu

The brief, from the owner in chat: add a button that returns from the relic hunt to the main
screen.

The hunt had no way back: the menu was reachable only by reloading the page. The pause card —
Esc on a keyboard, the pause button in the top-right corner on a touch screen — now has
**Main menu** next to the continue button. Progress is saved, the ship waits where it stopped,
and **Collect relics** carries on from there.

Checked in the desktop app's browser pane.
